# دليل التعديل والتطوير على واجهة المستخدم (UI Guide)

تم تنظيم كافة ملفات الواجهة الرسومية (Next.js 16 + React 19 + Tailwind v4) داخل هذا المجلد (`desktop/ui/`) لتسهيل التعديل المباشر عليها.

---

## 📂 خريطة وهيكل مجلد الواجهة (`desktop/ui/src/`)

### 1. مجلد الميزات الطبية (`src/features/`)
هنا تجد المكونات البرمجية لكل ميزة في العيادة مفصولة بدقة:
- **`examination/`**: شاشة فحص الأنف والأذن والحنجرة (ENT)، ولوحة الرسم التوضيحي بالفرشاة (Canvas Drawing)، وكتابة التشخيص والروشتة.
- **`appointments/`**: شاشات حجز المواعيد الجديدة، تعديل المواعيد، وجدول المواعيد اليومي.
- **`patients/`**: إدارة المرضى، البحث بالاسم الرباعي أو الهاتف، الملف الطبي وتاريخ الزيارات.
- **`queue/`**: شاشة طابور الانتظار التفاعلي اللحظي ونداء المريض التالي.
- **`closing/`**: شاشة الإقفال المالي واليومي للعيادة والإيرادات.
- **`expenses/`**: بنود المصروفات، الفئات، وتقارير الميزانية.
- **`home/`**: الصفحة الرئيسية الترحيبية وقسم الهيرو وشريط التنقل العلوي (Navbar).

### 2. مجلد الصفحات والمسارات (`src/app/`)
يستخدم Next.js App Router مع الصفحات المتوازية حسب صلاحية المستخدم:
- **`@doctor/`**: الشاشات الخاصة بالطبيب فقط (تظهر تلقائياً عند تسجيل دخول الطبيب).
- **`@receptionist/`**: الشاشات الخاصة بموظف الاستقبال (حجز، طابور، مدفوعات).
- **`@admin/`**: الشاشات الخاصة بمدير النظام (إعدادات، نسخ احتياطي، مصروفات).
- **`auth/login/`**: صفحة تسجيل الدخول الرئيسية.
- **`api/`**: مسارات API الداخلية للواجهة (proxy للـ backend والـ Socket.IO ticket).

### 3. مجلد المكونات المشتركة (`src/shared/`)
- **`components/`**: الأزرار، الكروت، الجداول، شارة التزامن اللحظي (`realtime-status-badge.tsx`).
- **`hooks/`**: خطافات React، وأهمها `use-clinic-realtime.ts` المسؤول عن المزامنة الفورية عبر الشبكة المحلية.

### 4. الصور والأيقونات (`public/`)
- يحتوي على صور الطبيب وخلفيات الصفحة الرئيسية وأيقونات الموقع.

---

## 🛠️ أوامر العمل السريع داخل مجلد الواجهة (`desktop/ui`):

```bash
# تشغيل خادم الواجهة في وضع التطوير والتعديل المباشر (Hot Reload):
pnpm dev

# بناء الواجهة للإنتاج بعد أي تعديل:
pnpm run build
```
أي تعديل تقوم بحفظه داخل `desktop/ui/src` ينعكس فوراً على تطبيق سطح المكتب!
